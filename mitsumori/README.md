# 栗駒見積帳（見積・原価管理アプリ）

Excel「栗駒見積帳」（案件・単価表・数量拾い・見積項目・原価表・見積書）と、PowerPoint の図面プレゼン、仕入先見積・補助金試算を **1つのアプリ** にまとめたものです。

| ファイル | 役割 |
|---|---|
| `index.html` | **担当者**：見積の作成（図面→数量→明細→利益率→見積書）、請求書の読み込み |
| `admin.html` | **管理者**：全案件の一括管理、単価表の編集と学習結果の反映、設定・担当者・バックアップ |

補助ファイル：`core.js`（計算の中核。画面に依存しない）／`drawing.js`（図面の取り込み・自動位置合わせ・トレース）／`importer.js`（請求書・仕入見積の読み取り）／`app.js`（画面）／`data.js`（Firebase・お試し・体験版の自動切替。匠協コネクトと同じ仕組み）／`config.js`／`styles.css`／`sw.js`・`manifest*.json`（PWA）。

## ご要望との対応

1. **現況図と完成図をドロップすると自動計算**（「① 図面から計算」）
   - PDF・画像をドロップ。PDF は図面の文字から **縮尺（S=1/100 など）** と **部屋の帖数（LDK 18帖 など）** を自動で読み、帖数から床・壁・天井の概算数量をすぐ出します。
   - 現況図と完成図を **自動で位置合わせ** し、変わった所を色付け（赤＝撤去、青＝新設）。
   - 部屋（面積・周長）／壁（長さ）／建具・設備（個数）をクリックでなぞると正確な数量に。**現況にあって完成にない壁＝撤去、完成にだけある壁＝新設**、建具は同じ場所なら既存・なければ新設、と比較して自動で数量化し、見積明細に自動反映します。
   - どの単価項目にどの数量を使うかは、単価表の「図面連動」で決めます（例：複合フローリング＝床の張替面積）。
2. **単価・数量は担当者が補正**（「② 見積明細」）：空欄＝自動、数字を入れると「補正」として黄色で残り、元の値（図面の数量・標準単価）も並べて表示。↺で自動に戻せます。図面を直しても補正は消えません。
3. **管理者が一括管理**（admin.html「一括管理」）：全担当者の案件を担当者・状況・月で絞り込み、見積総額・受注額・受注率・粗利率・実行金額を集計。状況の変更、CSV出力、全データのバックアップ／復元。
4. **請求書を読み込んで原価実行を集計し、標準単価を学習**（「請求書・原価」）
   - PDF（文字入りはそのまま、文字化け・スキャンは文字認識）・写真・CSV を読み、明細（品名・数量・単位・単価・金額・上代）を拾って、単価表の項目に名前の近さで自動で結び付け。**必ず確認・修正してから保存**します。
   - 案件ごとに **実行予算（見積原価）と実行金額（請求書）** を工種別に比較し、実行粗利を出します。
   - **学習**：請求書の実際の単価を、新しいほど重く（半減期は設定で変更）平均し、極端な値は除外。提案標準単価＝学習原価÷(1−目標粗利率)。管理者が「反映」で単価表に取り込みます（自動では書き換えない）。担当者が見積で単価を手直しした傾向も表示。
   - 仕入見積（上代・仕切）はそのまま見積明細に追加できます（原価＝仕切、売価＝上代×掛率 か 原価÷(1−目標粗利率)）。
5. **担当者は案件ごとに見積金額の利益率を調整**（「⑤ 金額・利益率」）
   - 「標準単価どおり」か「利益率を決めて原価から単価を出す」を選択。スライダーで利益率を動かすと金額がその場で変わります。工種ごとの利益率、**税込の目標金額から利益率を逆算** も可能。標準単価どおりとの差額も表示。
   - 諸経費率・値引き・補助金（予定）も案件ごとに設定。見積書には補助金を差し引いた実質負担額を参考表示します。

見積書（御見積書＋内訳明細書、A4）は「見積書」タブから印刷・PDF保存。消費税は1円未満切り捨て。

## 契約書・請求書（お客様向け）
- **契約書**（案件の「契約書」タブ）：Excel版と同じ書式の工事請負契約書を、甲保管・乙保管の2通まとめて印刷。工事名・工期・請負代金（税抜と消費税を区分記載）・支払方法（契約時／中間／完成時の割合と金額）を見積から自動で入れます。収入印紙の額は、工事価格（税抜）を建設工事請負契約書の軽減税率（令和9年3月31日まで、以後は本則）にあてはめた**参考額**。条文は管理者の「設定」で全案件共通に編集でき、案件ごとに特約を足せます。「契約したので受注にする」で状況も更新。
- **請求書**（案件の「請求書」タブ）：契約金・中間金・完成金・全額・追加工事を作成。金額は請負代金×支払割合（税抜を四捨五入、消費税は切り捨て、完成金で端数を吸収）。インボイスの記載事項（登録番号・税率ごとの対価と税額など）に対応し、登録番号や振込先が未登録だと警告します。請求番号 I-年-連番、支払期限は請求日＋設定日数。
- **請求・入金**（メニュー）：全案件の請求書を未入金／期限切れ／入金済で一覧。入金は「入金済」のチェックで記録するだけで、振込や入出金の操作はしません。全額入金されると案件を「完了」にするか確認します。
- 書式は参考例です。実際の契約前に約款・印紙税額を専門家にご確認ください。

## 3つの動作モード（自動切替）
1. **共有モード（本番）**：`config.js` に Firebase 設定があるとき。会社リンク（`?c=…`）で全担当者が同じデータを共有。
2. **お試しモード**：`firebase.apiKey` が空のとき。この端末だけで動作。
3. **体験版**：URL に `?demo=1`。サンプル案件（LDK改修・内窓工事・完了済み案件と請求書）入り、24時間でリセット。

## 始め方（本番）
1. 管理者が `admin.html` を開き「会社を登録」→ 会社名・管理者名・暗証番号（任意）を入れる。
2. 「設定」に出る **担当者用リンク** を担当者に送る（LINE 等）。担当者は開いて自分の名前を選ぶだけ。
3. 「設定」で会社情報（見積書に載る）・諸経費率・目標粗利率を、「単価表・学習」で自社単価を入れる（初期値は Excel 見積帳の例と同じ）。

### Firebase のルール（共有モードで使う場合・管理者が設定）
Firebase コンソール → Realtime Database → ルールに、既存ルール（rooms／kintai／shokunin／takyo など）を残したまま次を **追加** してください。匿名ログインは匠協コネクトと同じく有効になっている前提です。

```json
"mitsumori": {
  "companies": {
    "$ck": {
      ".read": "auth != null",
      ".write": "auth != null"
    }
  }
}
```

> **注意（重要）**：会社リンク（`?c=…`）を知っている人はその会社の見積（施主名・住所・金額を含む）を読み書きできます。リンクは社内の担当者だけに渡してください。管理画面の暗証番号は画面を分けるための簡易な鍵で、データそのものの保護は上記ルールとリンクの管理で行います。図面の画像も同じ場所に保存されます（1枚あたり数百KB）。

## 外部ライブラリ（すべて無料・ブラウザ内で処理）
- pdf.js（cdnjs）＋日本語の CMap（jsDelivr）… 図面・請求書 PDF の表示と文字の読み取り
- Tesseract.js（jsDelivr）… スキャン PDF・写真の文字認識。初回だけ日本語辞書（数MB）を読み込みます。**書類の中身は外部に送りません。**
- 有料 API は使っていません。

## 割り切り・今後
- 図面の線から部屋や壁を **完全自動で認識** するのは画像では難しいため、①帖数からの概算、②変更箇所の自動色付け、③なぞった図形の自動比較、の3段構えにしています。CAD の DXF 取り込みは未対応（要望があれば追加）。
- 文字認識の精度は書類の画質次第です。読み取り結果は保存前に必ず確認してください。
